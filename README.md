# AgroFlora 🌿🤖

AgroFlora es una aplicación backend desarrollada en **FastAPI** y **Supabase (PostgreSQL)** diseñada para el diagnóstico inteligente de enfermedades en plantas de floricultura mediante el procesamiento de imágenes y la gestión automatizada de inventarios agrícolas.

---

## 🚀 Requisitos previos

Asegúrate de tener instalado en tu equipo:

- **Python** (Versión 3.10 o superior recomendada)
- **Git**
- Un editor de código (como **Visual Studio Code**)

---
